# JING ATELIER — Website preview and deployment

A buildless, responsive English-language presentation website. The seven supplied photographs are included in `assets/`; all inquiry links point to Instagram `@jingzuoatelier`. No shop, prices, confirmed artist credits, or fixed class schedule are presented.

## Preview

Open `index.html` in a browser, or run a static server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Upload this folder to any static hosting provider (for example, Netlify Drop, Cloudflare Pages, GitHub Pages, or your own web host). Set the published/root directory to this folder; there is no build command. Keep `index.html` and the `assets` folder together. Connect a domain in the hosting provider if desired.

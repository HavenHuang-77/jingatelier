# JING ATELIER — Website

A responsive English-language showcase for curated Jingdezhen ceramics, Chinese ceramic culture, and onsite pottery teaching inquiries. All contact links point to Instagram `@jingzuoatelier`. The site has no shop, prices, or confirmed class schedule.

## GitHub Pages

This repository is prepared to publish from the `main` branch root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`. The `CNAME` file sets the custom domain to `jingatelier.com`; configure the DNS records at your domain registrar and enable HTTPS after GitHub verifies the domain.

The site is buildless. Keep `index.html` and the `assets` folder together. For local preview, open `index.html` or run `python3 -m http.server 8000` in this directory.

## Content notes

Visitor-facing copy is English-only. Images are presented as a curated visual selection without identifying specific makers, techniques, or product availability. Experience inquiries are subject to local availability and are not represented as confirmed bookings.
